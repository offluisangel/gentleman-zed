## Install using Git
If you are a git user, you can install the theme and keep up to date by cloning the repo:

```
git clone https://github.com/gentleman-zed.git
```

## Install manually
Download using the GitHub .zip download option and unzip them.

## Activating theme
Copy the gentleman.json file to ~/.config/zed/themes.
Select the theme (Settings ➡️ Select Theme ➡️ gentleman).
